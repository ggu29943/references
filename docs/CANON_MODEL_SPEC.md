# 正式设定对应的建模要求

文字原文见 [SOURCE_LORE.md](SOURCE_LORE.md)。人物以成年约二十岁女性呈现；长时间经历不用于把外观做成老年人。

- 身高 170 cm，身体修长匀称，不瘦弱、不丰腴。生成后以中立网格高度归一化并保持骨架对象缩放为 1。
- 及腰白发，无发饰；细软分束，附头发辅助骨骼，尚无 Unreal 物理资产。
- 天蓝瞳，无高光：移除人为高光几何；眼白、虹膜、瞳孔的镜面与涂层强度为 0，不发光。UE 导入后也须将眼材质 Specular 设为 0，避免引擎默认眼角膜高光改变设定。
- 偏白肤色，以低强度次表面散射表达柔和透光感；并非透明身体。
- 常服素色、极简、柔软叠穿，删除参考图中密集花纹、花形腰饰与仪式感长垂带，保留白衣、窄黑边与素色腰带。
- 双翼天生、纯白，展开约 6 m。采用肩、肘、腕三段骨链；隐藏为切换翼网格可见性，收拢为骨骼旋转，不缩小羽翼。已恢复的眼睛与羽翼不额外添加伤疤或残损。
- 气质偏松弛、克制；不是威严端坐的神像，也不是持续愤怒或濒死状态。保留轻微待机动作，不将故事中的痛苦直接做成猎奇外观。
- 裁衡的文字长度为二尺五寸；暂以 1 尺 = 1/3 m 换算，刃长约 0.8333 m。换算仅为制作假设，不作为世界观事实。

## 武器图文差异

后发八张武器参考图有银色护手、雕饰、深色剑鞘、花叶纹、剑首和珠饰剑穗；文字原设定为无护手无装饰的素剑。已经向用户询问最终依据，在未回复前以最新图片制作主展示版，并单独保留文字素剑版。两版是制作方案，不能解释为角色新增了两把剑或新的故事设定。图片版的花纹与亮面金属属于外观参考，不自动改写武器能力。

位格、修为、身世与人物关系用于理解角色，不凭空添加皇冠、符文、锁链、法阵或其他视觉标识。
