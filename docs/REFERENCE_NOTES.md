# 参考与待核对项

已查看五张用户提供的图片：整理羽翼日常图、无文字立绘、正面、侧面、背面。三视图用于常服轮廓，日常图用于羽翼外观。

可确认：银白长发与偏侧分的刘海、浅蓝色眼睛、偏白肤色、白色宽袖层叠长衣、黑色交领边与腰封、黑色长垂带、白色花朵装饰、深色低跟鞋。羽翼为成对的大型白色有羽翼，具有层叠长飞羽与小覆羽。

尚缺正式文字设定：身高、准确身体比例、羽翼真实尺寸与展开结构、羽翼有无或收放规则、特殊标志、具体年龄与身份设定，以及服饰纹样含义。模型身高约1.72m、翼宽约2.38m均是制作时的临时工作尺度，不是原设定事实。

接到文字设定后应优先核对外形约束，再修脸部与发型相似度、服装层数/花纹与羽翼形状。当前版本仍是可编辑、可导入继续制作的初版。
