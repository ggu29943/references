# 模型坐标与骨骼

Blender 4.3.2，单位米，Z 向上，角色面朝 -Y；角色自身左侧为 +X。临时工作身高约 1.72m，须依据正式设定调整。

| 部位 | 工作坐标／尺度（米） |
| --- | --- |
| 头部中心 | `(0, 0, 1.565)` |
| 头顶／下颌 | 约 `1.715 / 1.435` |
| 左右眼中心 | `(±0.043, -0.09, 1.581)` |
| 肩关节 | `(±0.17, 0, 1.35)` |
| 肘关节 | `(±0.285, -0.004, 1.12)` |
| 腕关节 | `(±0.36, -0.01, 0.925)` |
| 膝关节 | `(±0.083, -0.012, 0.52)` |
| 踝关节 | `(±0.083, 0, 0.11)` |

角色采用放松 A 姿。`root → pelvis → spine_01 → spine_02 → spine_03 → neck_01 → head` 为中央骨骼层级；双侧手臂、腿部与五指为 FK 变形骨。

额外骨骼链：`hair_back/l/r_01..03`、`skirt_front/back/l/r_01..03`、`sleeve_l/r_01..02`、`belt_l/r_01..03`、`wing_01..03_l/r`。它们可供动画与物理接管，当前没有现成的 UE 物理资产。

`src/common.py` 提供材质、网格、曲线、UV 球、带状曲面、放样与权重辅助函数。身体、衣物、头发和羽翼模块各自的 `build()` 返回模型对象；`src/build.py` 负责转换曲线、应用衣料厚度、统一骨骼、导出和渲染。`src/rig.py` 定义骨骼及待机动画。所有生成物可在 Blender 中继续编辑，重跑脚本会覆盖同名输出文件。
